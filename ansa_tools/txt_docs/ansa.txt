# Module: ansa

CompileScript
ansa.CompileScript(fileInput:str, fileOutput:str, moduleName:str, mode:bool=True) -> int
Creates a compiled (pyb/bsx) file from the given script path.
- fileInput (str): The path of the script that we want to compile.
- fileOutput (str): The destination path of the created compiled file.
- moduleName (str): The name of the module.
- mode (bool, optional): Declares whether to include the input script’s imported modules, inside the final compiled file.
(Applicable to all the imported modules, either through the native Python “import”, or through the “ansa.ImportCode” function)
-True, to include dependencies in the compiled script. (Default)
-False, otherwise.
It has effect only for Python scripts.
Returns: Returns 1 on success, 0 on failure.
Example:
import ansa

def main():
    ansa.CompileScript(
        "/home/user/scripts/some_script.py",
        "/home/user/scripts/some_script.pyb",
        "moduleName",
    )

if __name__ == "__main__":
    main()


ImportCode
ansa.ImportCode(path:str) -> int
This function imports the code from another python module (py or pyb).
- path (str): The name of the script file to import.
Returns: Returns 0 on success, else an exception is raised.

PybImport
ansa.PybImport(module_name:str, script_file_path:str) -> module
A function that imports python scripts (pyb).
Returns the imported module.
- module_name (str): The name of the module.
- script_file_path (str): The filepath of the script.
Returns: Returns the imported module.
Example:
import ansa

def main():
    x = ansa.PybImport("moduleName", "/module/file/path/moduleNameCompiled.pyb")
    x.funcInModuleNameCompiled()


ReadingFile

Function that returns the currently reading physical file on disk.
Returns: Returns the currently reading physical file on disk.
Example:
