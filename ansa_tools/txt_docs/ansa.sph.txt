# Module: ansa.sph

Body
ansa.sph.Body() -> None
The ansa.sph.Body is a class that is inherided from the KINETICS body. Therefore, this class supports all the kinetics properties but enhanced with some additional properties related to the SphSolver.
Example:
import ansa

idck = ansa.constants.NASTRAN

ent = ansa.base.GetEntity(idck, "SPH_SOLVER", 1)

solver = ansa.sph.Solver(ent)

body1 = solver.get_body("Body1")

if not body1.is_ground():
    body1["Adhesion"] = 0.25
    body1["Viscosity"] = 0.40


solver.simulate()

ExportForcesForStructuralAnalysis
ansa.sph.ExportForcesForStructuralAnalysis(deck: int, model: base.Entity, bodies: list[base.Entity], forces: list[ansa.sph.Sensor]) -> list[base.Entity]
Exports the forces from sph to ansa entities, so they can be easily used to Structural Analysis. Currently, only NASTRAN deck is supported.
- deck (int): The deck constant.
- model (base.Entity): Model where the entities will be created.
- bodies (list[base.Entity]): List of the A_RIGBODY or ansa.sph.Body entities that will be used on the Structural Analysis.
- forces (list[ansa.sph.Sensor]): List of the ansa.sph.Sensor objects. The ansa.sph.Sensor should be type of  "Pressure Force on Nodes". Returns -------
Returns: list[base.Entity] list of the created TLOAD entities. Raises ------ NotImplementedError If the 'deck' is not the NASTRAN deck. RuntimeError If the entities cannot be copies to the model. Examples --------
Example:
import ansa

idck = ansa.constants.NASTRAN

ent = ansa.base.GetEntity(idck, "SPH_SOLVER", 1)

solver = ansa.sph.Solver(ent)


ground = solver.get_body("Ground")
body1 = solver.get_body(1)
body2 = solver.get_body(2)

sensors = ansa.sph.SensorResults(ansa.base.GetEntity(idck, "SPH_SENSOR_RESULTS", 1))

force_sensors = sensors.collect("Pressure Force on Nodes")

model = ansa.base.CreateNewAnsaModel()
ansa.base.SetEntityCardValues(idck, model, {"Name": "Export Forces"})
tloads = ansa.sph.ExportForcesForStructuralAnalysis(
    idck, model, [ground, body1, body2], force_sensors
)

Sensor
ansa.sph.Sensor()
this class is used to add the SphSolver to export data from the solver after the simulation.
Example:
import ansa

idck = ansa.constants.NASTRAN

ent = ansa.base.GetEntity(idck, "SPH_SENSOR_RESULTS", 1)

sensors = ansa.SensorResults(ent)

sensor = sensors.collect("Point Force")[0]

time = sensor.timestamps()
value = sensor.data()
num = len(sensor)

for i in range(num):
    print(time[i], "  ", value[i])

Sensor.data
ansa.sph.Sensor.data(smooth: bool = False, smooth_options: dict = {}) -> [list[float], list[list]]
Returns the sensor data. If the sensor is scalar then a list with float values will be returned else a list contained 3 lists of floats will be returned.
- smooth (bool, optional): If 'True' the data are smoothed out.
- smooth_options (dict, optional): Dictionary with instructions about the smoothing. Currently, the only supported keyword is "width". Returns -------
Returns: [list[float], list[list]] Raises ------ ValueError If the 'width' is not type 'float' Examples --------
Example:
import ansa

idck = ansa.constants.NASTRAN

ent = ansa.base.GetEntity(idck, "SPH_SENSOR_RESULTS", 1)

sensors = ansa.SensorResults(ent)

psensor = sensor.collect("Point Force")
sensor = psensor[0]

force = psensor.data()
force_sm = psensor.data(smooth=True, smooth_options={"width": 0.5})

for i in range(len(force)):
    fi = force[i]
    fsmi = force_sm[i]

    print(fsmi - fi)

Solver.simulate
ansa.sph.Solver.simulate(initial_state: int = 0) -> ansa.sph.Info
Calls the SphSolver.
- initial_state (int, optional): Sets the initial state to start the simulation. Please see the method sph.Solver.states() and the class ansa.sph.States. Returns -------
Returns: ansa.sph.Info Returns object that has corresponding info about the Solver progress. Raises ------ TypeError Raises when at least one of the Solver properties has a different type than the nominal type. ValueError Raises when the user requests an initial_state but no states are loeaded. Also, the exception raises if the requested "inital_state" is out-of-bounds. RuntimeError Raises in cases where the license cannot be checked out. Examples --------
Example:
import ansa

dck = ansa.constants.NASTRAN

# Create Ansa Entity of type "SPH_SOLVER"
ent = ansa.base.CreateEntity(dck, "SPH_SOLVER", {"Name": "SphSolver_demo"})

# Create an instance of sph.Solver
solver = ansa.sph.Solver(ent)

# Set simulation time to 2 sec
solver["Simulation.Time"] = 2.0

# simulate the model starting from t = 0
solver.simulate()
